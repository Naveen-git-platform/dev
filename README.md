# Hyderabad Healthcare Atlas

An interactive, research-oriented map of healthcare facilities across Hyderabad, Telangana. Built with Next.js, TypeScript, Leaflet, and OpenStreetMap/Overpass data.

## Status
Initial project scaffold. Facility coverage depends on OpenStreetMap community data and Overpass API availability; results are not an official or complete medical directory.

## Development

```bash
npm install
npm run dev
```

## Data and attribution
Map tiles and facility data are provided by OpenStreetMap contributors. See https://www.openstreetmap.org/copyright. Facility discovery uses the Overpass API. Respect public API usage limits. Do not use this map as the sole source for emergency care or clinical decisions.
